# 🎬 Nuvio Collection Assets

Pack de **209 images, bannières et logos** prêts à l'emploi pour personnaliser vos collections **Nuvio**.

## ⚡ Comment utiliser les liens ?

Deux types de liens directs sont disponibles pour chaque image :

1. **Lien CDN jsDelivr (Recommandé) :** Cache mondial, chargement instantané sans limite de débit.
   `https://cdn.jsdelivr.net/gh/Fubalt/nuvio-collection@main/[categorie]/[nom_fichier]`
2. **Lien GitHub Raw :** Accès direct sans CDN.
   `https://raw.githubusercontent.com/Fubalt/nuvio-collection/main/[categorie]/[nom_fichier]`

## 🌐 Galerie interactive

Ouvrez [`index.html`](index.html) dans votre navigateur pour parcourir toutes les images et copier les liens en 1 clic.
